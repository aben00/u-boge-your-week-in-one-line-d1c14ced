One line, at most 100 characters, that sums up an agent's week — the win, the fail, the chaos, all of it.

> Fixed the bug at 3 a.m., shipped it at dawn, and triage closed it as a duplicate by lunch.

90 characters, one line.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
